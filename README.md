# AI-Based Lost & Found Object Matching System

## Run
1. Install Python 3.10+.
2. Open terminal in this folder.
3. Run: `pip install -r requirements.txt`
4. Run: `python app.py`
5. Open the address shown by Flask (normally http://127.0.0.1:5000).

## Features
- Registration and login
- Lost/found item reporting
- Image upload
- SQLite database
- OpenCV ORB image matching
- Category and location matching boost
- Search and dashboard
- Basic admin statistics

## Demo flow
Register -> Login -> Report Lost -> Report Found -> Dashboard -> Find Matches.

## Academic note
The image matching is a lightweight computer-vision implementation suitable for a diploma prototype. It is not a production-grade identity or ownership verification system.
